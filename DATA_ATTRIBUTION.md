The source contains anonymised historical Brazilian marketplace orders. This case selects a January 2017–June 2018 purchase cohort, excludes no order from the overall cohort because of missing outcomes, derives explicit metric-eligibility flags, aggregates child tables, selects a latest valid review, adds analytical case codes and produces summaries and visualisations. These modifications and derived data are shared under CC BY-NC-SA 4.0. The raw archive is not redistributed in the public repository or portable bundle.

Original project code is MIT licensed under LICENSE. The data and derived analytical outputs are not relicensed as MIT. The included Microsoft Power BI base theme and scaffold notices retain their separate MICROSOFT_LICENSE and MICROSOFT_NOTICE files.

Source file sizes and SHA-256 hashes are in reports/source_manifest.json. The model omits customer identifiers, fine geography and review comments. Raw staging/local inputs are excluded from Git.
